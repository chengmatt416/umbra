# Umbra 介面重設計 v1（待審）

2026-10-18。設計稿：[Figma「Umbra 重設計 v1」](https://www.figma.com/design/OZe5gK705PUHyOXE7y1tYd)（00 總覽、01 簡易模式、02 Capsule、03 圈選畫面、04 Power 模式、05 Dev 模式、06 帳號與模型、07 首次設定、99 元件）。本文件記錄每個決定的理由。審核通過前不動程式碼。

第二輪修改（同日）：模型三種模式都能選、清單從伺服器自動更新、可輸入其他模型；OpenAI／Anthropic 登入改成瀏覽器自動回傳；Capsule 依鏡頭大小擴張、可往中間滑收起；新增 Dev 模式；背景畫面與 Linux 桌面保留；Laya 在首次設定詢問下載；啟動時檢查 OTA；主題可選可客製；節點與 Git 保留；資源配置只有 Dev 能手動調。

## 1. 為什麼要改

現況：底部 4 個分頁（首頁、任務、目前、收件匣）＋側邊抽屜 21 個頁面，Capsule 在相機孔旁邊，點開後操作在螢幕下方的 Quick Composer。問題：

- 同一件事分散在多處：一個任務的對話在「目前」，等你批准在「收件匣」，它的終端在「終端機」，它的變更在「提交」。
- 一般使用者用不到的控制頁和日常功能放在同一層。
- 首頁有 Orb、eyebrow、說明文字等裝飾，畫面主體不是使用者的任務。
- Capsule 點開後眼睛要從上方跳到下方。

## 2. 三種模式

規格原型的手機體驗叫 Agent Mode，工程控制面叫 Power Studio。重設計做成三種模式，資料與執行完全一樣，只差顯示多少、誰配置資源：

| | 簡易（預設） | Power | Dev |
|---|---|---|---|
| 對象 | 一般使用者 | 進階使用者 | 開發者 |
| 選模型 | 可以（輸入列左邊） | 可以＋推理／視覺／快速／備援分工 | 同 Power |
| 即時畫面 | 顯示在對話裡 | 「畫面」頁自己看、接手 | 同 Power |
| 任務頁 | 對話 | 對話・步驟・終端・變更 | 同 Power |
| 右下選單 | 圈選畫面、帳號與模型、設定 | 圈選畫面、工作區、畫面、節點、安全、設定 | 「安全」換成「開發者」 |
| 資源配置 | 系統自動 | 系統自動 | 手動 |
| Capsule 卡片 | 暫停、停止 | ＋開啟、取回螢幕、切換工作階段 | 同 Power |

首次設定只問簡易或 Power；Dev 在設定第一列的三段切換裡。切換不重啟任何 Runner（INV-001）。

## 3. 合併

| 新位置 | 模式 | 合併了 |
|---|---|---|
| 首頁（任務） | 全部 | 首頁、任務、收件匣（「等你」篩選，批准直接在列上） |
| 任務頁 | 全部 | 目前、該任務的終端、步驟時間軸、即時畫面 |
| 工作區 + Git | Power、Dev | 工作區、儲存庫、提交、終端機；提交前檢查、提交並推送（憑證由代理保管） |
| 畫面 | Power、Dev | 顯示器（背景畫面）、Linux 桌面 |
| 節點 | Power、Dev | 遠端節點（配對、離線、撤銷照實顯示） |
| 安全 | Power | 憑證保險庫、審核紀錄、安全與證據、緊急停止（長按全部停止） |
| 開發者 | Dev | 原版 21 頁照「調度／信任／系統」分組，進去和原版一樣 |
| 設定 | 全部 | 設定、模型、外觀、Laya、更新、權限 |

資源、排程、槽位、保證額度：簡易與 Power 由系統依記憶體、溫度、電量自動分配；只有 Dev 的「資源與配置」能手動調。

## 4. 右下角按鈕（M3 Expressive FAB menu）

- 右下，距邊 16dp，在手勢列之上。單手持握約 49%（Hoober 2013, n=1,333），右下到中間是拇指最容易、最準的區域。
- 點擊後 FAB 變成關閉鈕，選項從上方長出（M3 規則：2–6 項，錨定 FAB 原位）。
- 設定裡可選慣用手「左」，FAB 與選單鏡像到左下。
- 底部同一列：左邊輸入列（含模型選擇），右邊 FAB。沒有底部分頁列、沒有抽屜。

## 5. Capsule

### 依鏡頭大小自動擴張

膠囊分成「左區｜鏡頭槽｜右區」。鏡頭槽寬 = 鏡頭寬 + 左右各 8dp，由 `DisplayCutout` 讀到的實際位置與大小決定；左右兩區等寬，所以膠囊永遠以鏡頭為中心，伴侶與文字不會被鏡頭擋住。設計稿示範 10dp、14dp、40×16dp 三種鏡頭（膠囊 242／246／272dp）。

| 狀態 | 左區 | 右區 |
|---|---|---|
| 閒置 | 小伴侶 | — |
| 執行中 | 伴侶 + 短標籤 | 經過時間 |
| 需要你 | 琥珀環伴侶 + 「需要你確認」 | 數量 |
| 多個任務 | 最多 3 個伴侶 + 標籤 | +N |
| 收起 | 伴侶 | 小點（仍在執行） |

### 手勢

- 點擊：在原位展開成卡片（頂端仍貼著鏡頭）。常用按鈕放在卡片底部；也可從膠囊往下拉展開。
- 往中間滑（像 iPhone 動態島）：收起成「收起」狀態，任務繼續。往外滑或點擊還原；需要你時自己變回「需要你」。
- 長按：圈選畫面。

卡片內容：標題列、上一步／目前／下一步、需要你時的允許／拒絕（48dp）、補充指示輸入列（不自動彈鍵盤）、動作列。

## 6. 圈選畫面（參考 Circle to Search）

觸發：長按 Capsule、Capsule 卡片的「圈選」、右下選單、或設為預設助理後的系統助理手勢。截圖凍結 → 鼠尾草綠光暈從底邊掃上 → Capsule 原地展開成圈選卡片 → 圈、點（吸附到無障礙節點）、塗過文字 → 收斂成圓角框＋四角把手 → 卡片長出縮圖與依內容的動作 → 送出後卡片收回成膠囊、回到原 App，膠囊顯示新任務。

所有控制都在 Capsule 卡片裡（已決定）：關閉、即時開關（預設關，單次快照）、縮圖、動作、輸入列。卡片在上、鍵盤在下，選取框不會被擋。

## 7. 即時畫面（背景畫面與 Linux 桌面）

- 簡易：模型在背景畫面或 Linux 桌面操作時，畫面即時顯示在對話裡的一張卡片；點一下開對話框放大，「接手」立即收回控制（INV-005）。
- Power／Dev：「畫面」頁有兩個分頁：背景畫面（每個顯示器的預覽、全螢幕、接手）、Linux 桌面（X11；觸控當滑鼠，可叫鍵盤、切觸控板模式、接手）。

## 8. 模型與帳號

### 選模型

- 三種模式都能選：輸入列左邊的模型晶片 → 模型清單。預設「自動」。
- 清單從 Umbra 伺服器自動更新（顯示「N 分鐘前更新」），和 omp 自帶的清單合併；只有已連線供應商的模型可選，其餘標「連接後可用」。
- 最下面「其他模型…」：選供應商、輸入模型 ID，送出前先試一次。
- Power／Dev 另有分工頁（推理、視覺、快速、備援、只用本機模型），頁尾顯示清單來源與「重新整理」。

### 登入

| 供應商 | 帳號登入 | API 金鑰 |
|---|---|---|
| OpenAI | 用 ChatGPT 帳號登入 | sk-… |
| Anthropic | 用 Claude 帳號登入 | sk-ant-… |
| Google Antigravity | 用 Google 帳號登入 | 無 |
| 其他相容 API | — | 網址、金鑰、模型 |

帳號登入一律是瀏覽器 OAuth＋本機回呼（loopback redirect）：Umbra 開瀏覽器，同時在本機等待回呼；登入完成瀏覽器自動導回，Umbra 換成憑證、存進保險庫、顯示「已連線」。不用裝置代碼、不用貼授權碼。實作驅動 omp 既有的流程，三家都已經是本機回呼伺服器（`pi-catalog/src/compat/rules/auth/*.kdl`）：OpenAI `localhost:1455/auth/callback`（OpenAI 只允許這個 URI，埠被占用會失敗而不換埠）、Anthropic `localhost:54545/callback`、Antigravity `127.0.0.1:51121/oauth-callback`。omp 在 Linux 環境裡跑，和手機共用網路，所以手機瀏覽器導回 localhost 就會被它收到。Anthropic 的「貼上授權碼」只是瀏覽器連不到本機時的備援，App 不顯示它，失敗時改成「重試」。

風險（已決定在登入頁保留一行琥珀色提示）：Anthropic 2026-02 把「第三方工具使用訂閱 OAuth」寫進條款禁止；Google 自 2026-02 起停用在第三方工具用 Antigravity 登入的帳號（含付費方案）；OpenAI 的「用 ChatGPT 登入」只在 Codex 官方文件出現，第三方使用是灰色地帶。

## 9. Laya

首次設定第 3 步只問一次是否下載（建議 Wi-Fi，大小由伺服器提供後顯示）。下載在背景進行，可直接繼續下一步，完成後通知一次。權重存在 App 私有儲存，App 更新不用重新下載；之後每次開始任務自動啟動 `laya-serve`。設定裡顯示「已下載・開始任務時自動啟動」。

## 10. 更新（OTA）

- 每次開 App 在背景檢查一次 update.json；有新版才跳對話框「有新版本 x.y.z」［稍後］［更新］。
- 選更新後全部自動：下載、驗證簽章、安裝、重新開啟。有 helper／root 時靜默安裝；執行中的任務先到安全點。進度留在首頁上方一行，不擋操作。
- 設定的「更新」列可以手動觸發同一流程。

## 11. 外觀

Porcelain、Liquid、Apple 三個主題照舊可選。Liquid 可調色相；Apple 可開「完整 Liquid Glass」；「動態效果」開關（省電或過熱時自動停）。切換時保留原本的倒入動畫。

## 12. 首次設定

1 選模式（簡易／Power）→ 2 連接模型 → 3 Laya → 4（下載在背景）→ 5 權限（操作其他 App、顯示 Capsule、通知；Root／Shizuku 在進階設定）。

## 13. 簡潔規則（刪掉的）

首頁 Orb hero、eyebrow 小字、標語、說明卡片、只為好看的統計磚、抽屜、底部分頁列、每頁頂部的說明段落。保留：Porcelain 色彩、Geist + Newsreader、伴侶（它表示狀態）。

## 14. 已決定（2026-10-18）

1. 圈選時的輸入與控制都在 Capsule 卡片裡。
2. Anthropic／Antigravity 登入頁保留一行琥珀色條款風險提示。
3. 模型清單放在 umbra-agent.pages.dev（和 update.json 同一處，例如 `/models.json`）。
4. 舊頁面的通知深連結改指向新位置（例：收件匣 → 首頁「等你」篩選）。
